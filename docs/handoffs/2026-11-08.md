## What landed

- **CMB-122 (#75).** `package.json` gains `exports` pointing at `src/lib.js`, an entry with no side effects. `buildConfig(object)` runs parseConfig's validation on a plain object. A null optional field
  reads as absent, so a built config can be fed back in.
- **CMB-124 (#73).** `runVerdict(config, { keys })` takes service-level keys and needs no `secrets` in the config. The degraded list goes to the log only, because a missing optional key is already
  charged through its signal's unknown result.
- **CMB-126 (#77).** `[signals] events` and `trackwork` switches, both default true. A switched-off signal is null (not consulted). Rail alerts still run when track work is off.
- **CMB-128 (#78).** `opts.sink(row)` receives `derivedRow()` instead of the Sheets write. That row drops every raw Routes duration and distance, the congestion metres and the verdict's trip minutes;
  margins stay. A sink failure or stall is `logged.ok = false` and never costs the verdict.
- **CMB-130 (#74, #76).** `findFork` (30 m tolerance, statuses diverges, identical, disjoint) and `approachPoint` in `src/fork.js`, both exported from the package.
- **CMB-133 (#79).** Every result carries `attributions` as `{ source, text }`: Google first, then each signal that returned data. The DDOT terms reading is UNVERIFIED.
- **CMB-159 (#80), code only.** Each active track-work window is put to the lab's decision model (`/v1/systemone`, model `jev`, since clef-flash was retired) and logged in three new columns:
  `trackwork_model_p`, `trackwork_penalty_shadow`, `trackwork_model_error`. The applied penalty stays the flat 0.2. With `TRACKWORK_MODEL_URL` unset the model is not asked, and production has it unset.
