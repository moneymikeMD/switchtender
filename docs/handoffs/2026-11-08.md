## Recent Wins

- **A paid service can build on the engine.** switchtender imports as a package pinned to a release tag (v1.11.0), with no npm publish. Through it a multi-user service can:
  - build a rider's config from stored data, with the same validation the config file gets;
  - run verdicts on its own service-level API keys, so no per-user secrets;
  - switch off data feeds it is not licensed for, which then read as not consulted rather than clear;
  - send each verdict to its own store as a row that leaves out Google's raw durations, distances and geometry;
  - find where a rider's drive to work and drive to the lot part ways, and the point to wake the app a chosen distance before it;
  - show who supplied the data behind every verdict.
- **Track-work notices can be judged by the lab's decision model.** For each notice, the model is asked whether it slows the rider's own stretch in their direction of travel. The answer is logged
  next to today's flat penalty and changes nothing yet. Its three columns are already in BigQuery.
- **Three long watches closed with evidence.**
  - The Ticketmaster rate limit is fixed: no venue lookup was refused across 358 verdicts since late September.
  - Hourly morning sampling runs six times every weekday.
  - Evening sampling of the trip home ran exactly five times on every weekday for two weeks.
- **The evening ride home is live.** The release is deployed, and the live config carries the station where the ride comes above ground.
