# 2026-09-26: arrivals are collected end to end, and the hostname left the repo

Saturday at home. The phone side of CMB-41 was built and tested, the
BigQuery side landed, and the service's public hostname was taken out of
every tracked file after the owner pointed out that a public repo should not
advertise where to send traffic. 326 tests pass. No deploy today; Cloud Run
still runs `switchtender-00013-wsc`, which already serves `/arrived`.

## What changed and why

- **`switchtender.arrivals` in BigQuery (PR #29).** `scripts/bq-external-table.sh`
  defines both tables now, schemas from `FULL_HEADER` and `ARRIVALS_HEADER`
  in `src/log.js`. Run live with a Drive-scoped gcloud credential
  (`gcloud auth login --enable-gdrive-access`); the join returns the
  2026-09-22 arrival beside its verdict.
- **Service hostname is private (PRs #31, #32, #33).** A doc-only PR added
  the mapped domain, was reverted the same hour, and every `.run.app` host
  was scrubbed with it. The URL now has two homes: `[service] url` in the
  gitignored `config.toml`, validated as an https origin, and 1Password
  `op://Software_Development/Switchtender/service url`. Docs say
  `<service>`. Rule 2 means the old host stays in history; the point is
  discoverability, not secrecy.
- **Three macros, one category export (PR #34).** `docs/switchtender.category`
  replaces `docs/switchtender.macro`: fork trigger plus the park and office
  arrival macros sharing the global `st_took`. Host, key, last response and
  parsed JSON blanked before commit.

## Arrival macros, tested by hand

Both fired manually from home. Park wrote `took = transit`; office carried
it. Three repeat office fires on the same date wrote nothing. One mistake
the request log caught: the office macro was cloned from park and its
Set Variable sat above the HTTP Request, so the reset ran before the send.
`gcloud run services logs read` shows the `took=` query value, which is the
quickest way to check the phone's state without touching it. Test rows were
deleted from the sheet by hand; the tab holds only the 2026-09-22 row.

Fences are 150 m. Time-of-day constraint on both arrival macros is
05:30 to 11:00 weekdays, which excludes an evening return; that is fine for
scoring a morning verdict and worth remembering if arrivals ever go missing.
