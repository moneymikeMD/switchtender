# Handoff: 2026-09-16 evening

Second session of the day. It took the engine from "computes two options" to
a deployed, spoken, logged verdict fired from the owner's phone, and made the
repository public. `CLAUDE.md` has the standing rules; this note covers what
changed, what was verified, and what is left.

## What changed

- **Verdict rule and spoken line (CMB-10).** `src/verdict.js`. Drive only when
  `transit - drive > floor * (1 + 3 * congestion)`; transit wins ties. Every
  penalty is a documented starting guess. Spoken line is verdict, times,
  reasons, confidence band, verdict again, capped at three reason clauses
  (owner decision after hearing five).
- **Seven signals feed confidence, none flips the choice.** Google Routes
  (durations, congestion), TomTom DC incidents (`src/incidents.js`, a live
  crash or a closure under 2 h old marks the drive unstable), CHART Maryland
  records matched to the polyline (`src/chart.js`), DDOT layer-11 closures
  matched to the polyline (`src/closures.js`), Ticketmaster venue events with
  MLB's keyless schedule for the ballpark (`src/events.js`, `src/mlb.js`),
  WMATA planned track work scraped from wmata.com (`src/trackwork.js`).
- **Logging (CMB-11).** One 47-column row per verdict to the Sheet tab
  `verdicts`, BigQuery external table `switchtender.verdicts`. Locally the
  token is `SHEETS_ACCESS_TOKEN=$(gcloud auth print-access-token)`; on Cloud
  Run the service account's metadata token. BigQuery schema still covers the
  original 41 columns; rerun `scripts/bq-external-table.sh` once the extras
  are folded into `HEADER`.
- **Cloud Run (CMB-12).** `src/engine.js` is the one pipeline; `src/index.js`
  is the CLI, `src/server.js` the HTTP face. `GET /verdict` behind
  `X-Switchtender-Key`, `/health` unauthenticated. Revision 00005 at
  https://<service>. Deploy with
  `scripts/deploy-cloud-run.sh` (`--update-config` after editing
  `config.toml`, `--rotate-secret` to mint a new shared secret).
- **Phone (CMB-17).** `docs/switchtender.macro` is the MacroDroid macro, built
  against MacroDroid's published AI schema and round-tripped through the
  owner's phone. Import steps in `docs/phone.md`. Two values live on the
  phone only: the geofence and the local variable `st_key`.
- **Public (CMB-24).** History rewritten with filter-repo to one author
  identity and no contractor contact details in fixtures, then flipped.
  History is now fixed; anything committed is published.
- **Tooling.** Node 24 via nvm (`.nvmrc`), Homebrew node removed. 217 tests.
  This repo does not run the night-watchman operating model (owner decision).

  braces, `{lv=st_json[spoken]}`; a zsh loop variable named `path` clobbers
  `PATH`.

## Loose ends

- **Confidence stacks fast.** Seven penalties from 1.0 can land at 0.4 on a
  busy evening. Tune once the Sheet has a few weeks of rows; every penalty
  is a named constant in `src/verdict.js`.
- **Closure radius and CHART radius** are 300 m and 400 m point-to-vertex
  guesses; a permit midway along a long straight polyline gap can be missed.
- **Weather** still has no key and no column; `SECRETS` in `src/config.js`
  lists four.
- **Conversational layer** (asking by voice) remains deferred by design.
- **Secrets on the phone.** MacroDroid's system log prints variable values
  and fused GPS fixes in plain text. Never paste that log anywhere.
