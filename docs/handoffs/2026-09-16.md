# Handoff: 2026-09-16

This session founded the repository, settled the data sources, and built the
engine through the point where it computes both options. `CLAUDE.md` has the
standing rules. This note covers what was in progress and what comes next.

## What changed

- **The repo exists.** It holds the config contract, a Node scaffold, and the
  route engine: four commits, 26 tests passing, verified from a fresh clone.
- **The engine computes both options from the fork.** Keep driving is one
  request. Park and ride is a drive to the park-and-ride, plus the platform
  buffer, plus a transit leg. Congestion is weighted by distance along the
  decoded polyline, not by point index. In the test fixture the two methods
  give 70% and under 6% for the same route, so the choice matters.
- **Every data source is decided,** each backed by a live query.
  See the table in `CLAUDE.md`.
- **The backlog was rescoped to match.** v1-era tickets are cancelled. CMB-8
  was rewritten because it still told the next agent to delete v1 in place and
  commit real coordinates.

## Verified vs. assumed

- **Verified:** tests, clean-clone install, the startup failure paths, and live
  queries against TomTom, MapQuest, Ticketmaster, CHART, DDOT TOPS, and WMATA's
  REST, GTFS-RT, and track-work page.
- **Not verified:** the route engine has never called the Routes API with a
  real key. A deliberately bad key returns a clean HTTP 400 and no verdict, but
